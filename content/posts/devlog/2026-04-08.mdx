> **메타 설명:** GitHub 활동 제로인 날의 개발일지. 코드를 안 짠 날도 개발자의 하루다.
> **키워드:** 개발일지, 빌드인퍼블릭, 사이드프로젝트, 개발루틴, 번아웃

오늘 아침 GitHub 대시보드를 열었다. 커밋 0, 이슈 0, PR 0. 초록 잔디가 아닌 회색 칸이 나를 맞이했다.

## Overnight Recap

어젯밤부터 오늘 아침까지 움직인 게 없다. 활성 레포도 없고, 열린 이슈도 없고, 리뷰 대기 중인 PR도 없다. 자동화 파이프라인이 돌 것도 없으니 CI/CD 로그도 조용하다.

솔직히 말하면 어제 저녁에 좀 지쳤다. 코드를 열었다 닫았다만 반복하다가 그냥 덮었다. 이런 날이 있다. 매일 커밋하는 게 목표가 되면 의미 없는 커밋을 찍게 되고, 그건 기록이 아니라 소음이다.

## Today's Plan

잔디 심기용 커밋을 만들 생각은 없다. 대신 오늘은 방향을 잡는 데 쓸 생각이다.

- 진행 중이던 사이드프로젝트들의 TASKS.md를 다시 훑어본다
- 멈춰둔 레포 중에 이어갈 만한 게 있는지 판단한다
- 하나를 골라서 이슈를 쪼개고, 내일 바로 손댈 수 있는 상태로 만든다

코드를 안 짜는 날이라도 맥락을 유지하는 건 중요하다. 내일의 나한테 온보딩 문서를 써주는 셈이다.

## One Liner

커밋 그래프가 비어 있어도 개발자는 쉬는 게 아니라 숨 쉬는 거다.
