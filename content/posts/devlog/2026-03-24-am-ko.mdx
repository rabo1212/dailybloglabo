## 시작 — 1월 9일

2026년 1월 9일, `menuqr`이라는 레포를 만들었다. QR코드로 식당 메뉴를 보여주는 간단한 웹페이지. JavaScript 파일 하나짜리였다. 코딩 경험은 거의 없었다. AI한테 "이거 만들어줘"라고 하면 뭔가 나온다는 걸 알게 된 게 전부.

다음 날 `daily-planner`를 만들었다. HTML 한 장. 그 다음 주에 `storyboard_ai`. 뭘 만들어야 할지도 몰랐지만 일단 매일 뭔가를 만들었다.

## 1월: 뭐든 만들어보자 (20개)

1월 17일부터 폭발했다. 하루에 5개씩 레포를 파기 시작했다.

- **빌런테스트** (`villain-test`, `wokrvillain-test`) — 심리테스트 류. "너는 어떤 빌런?" 같은 거
- **레몬게임** (`lemongame`) — TypeScript 첫 시도
- **뱀서라이크** (`survive`) — 게임 만들기에 빠졌다
- **2048게임** (`2048game`) — "이것도 만들 수 있나?" 해서 만들어봄
- **사랑파괴범** (`love-destroyer`) — 이름부터 강렬한 심리테스트
- **회복식단** (`healing`) — 건강 관련 앱도 도전
- **텔레그램 주식봇** (`stock-bot`) — API 처음 건드려본 순간

솔직히 이때 만든 것들 대부분은 완성도가 낮다. 하지만 그게 핵심이었다. "이것도 되네?" "저것도 되네?" 하면서 감을 잡아가는 과정.

1월 20일에 `visiblerayhomepage_1`(가시광선 홈페이지)를 만들었다. 실제로 쓸 수 있는 웹사이트를 처음 만들어본 날이다.

1월 22일, **Imaginary Story** (`imaginary-story`). AI 스토리보드 생성 웹앱인데, 이때부터 "이걸로 진짜 서비스를 만들 수 있겠다"는 생각이 들기 시작했다. React+TypeScript+Vite 조합을 처음 써봤다.

1월 25일엔 `data_ipji`(입지분석), `fairytale-photo`, `jiwonhae-`(정부지원사업페이지)를 동시에 진행했다. 실용적인 것도, 재미있는 것도, 돈이 될 만한 것도 닥치는 대로.

1월 27일, **믿독** (`subscription-manager`). 구독 관리 앱. 이게 나중에 Supabase 연동해서 실제 서비스로 배포까지 간다.

**1월 총 레포: 25개. 17일 만에.**

## 2월: 진짜 만들기 시작 (20개)

2월부터 방향이 바뀌었다. "일단 만들어보자"에서 "제대로 만들어보자"로.

2월 8일에 하루에 4개를 시작했는데, 그중 `past-life-test`(전생테스트)가 있었다. MBTI 기반 전생 심리테스트인데, 실제로 사람들이 쓸 수 있는 수준으로 만들어봤다.

2월 9일 `gangwon-travel` — 강원도 여행 루트 추천. React + 카카오맵. 지도 API를 처음 다뤄본 날.

2월 12일, **바이낸스 현물 매매봇** (`binance-spot-bot`). Python이었다. JavaScript만 하다가 Python으로 넘어간 첫 프로젝트. 실제 돈이 걸린 거라 진지해질 수밖에 없었다. RSI, MACD, 그리드 전략 같은 걸 코드로 짜면서 "아 이게 개발이구나" 싶었다.

2월 19일 `second-brain` — 세컨드브레인 자동화. 매일 아침 실행되는 크론잡으로 뉴스를 모아서 정리해주는 시스템.

2월 21일이 터닝포인트였다. 하루에 4개 프로젝트를 런칭했다:
- **천명** (`chunmyeong`) — AI 사주×관상 분석. Claude API 연동, Next.js, Vercel 배포까지 한 번에
- **냥멍천명** (`chunmyeong-pet`) — 반려동물 버전
- **퀀텀리프** (`quantum-leap`) — AI/반도체 종목 모니터링 대시보드
- **미션 컨트롤** (`mission-control`) — 전체 프로젝트를 관리하는 대시보드

이때부터 프로젝트가 서로 연결되기 시작했다. 미션 컨트롤이 다른 프로젝트들의 상태를 추적하고, 세컨드브레인이 매일 아침 브리핑을 만들어주고.

2월 25~27일에 **마작플레이**, **뽀모도로**, **고스톱플레이** — 게임 3종을 연달아 만들었다. Next.js + TypeScript가 손에 익어서 속도가 붙은 시기.

## 3월: 시스템 단계

3월은 개별 프로젝트보다 시스템을 만드는 데 집중했다.

`quantum-leap-v2` — 퀀텀리프를 멀티에이전트 AI 분석 시스템으로 업그레이드. Claude Haiku 13회 + Sonnet 1회 = 14회 API 호출로 한 종목을 분석하는 파이프라인. Bull vs Bear 3라운드 토론까지 시키는 구조.

`rabo-command-center` — 가재군단 30마리를 관리하는 커맨드센터. AI 에이전트 7개 부서, 30개 페르소나.

그리고 오늘, `dailybloglabo` — 지금 이 블로그. 5개 탭에서 하루 10개 포스트를 AI가 자동 생성하고 배포하는 시스템. 이걸 만드는 데 반나절 걸렸다.
