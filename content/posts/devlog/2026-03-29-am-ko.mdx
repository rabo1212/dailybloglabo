어느덧 강원 여행 플래너 앱 개발도 1달이 다 되어가네요. 처음에는 AI 만으로 만들 수 있을 거라 생각했는데, 막상 실제로 구현해 보니 생각보다 많은 작업이 필요했습니다. 하지만 계속해서 새로운 기능을 추가하고 개선해 나가며 점점 더 완성도 있는 앱으로 발전시키고 있습니다.

## 29일차

오늘은 정부 프로젝트의 제안서 작업을 했습니다. 「2026 강원 관광 통합 브랜딩 팝업스토어 운영 대행용역」이라는 제안서를 정리했는데, 총 예산이 285억 원이나 되는 대규모 사업이었습니다. 

제안서의 핵심 콘셉트는 "디비디비딥(DB-DEEP) 강원: 플레이 그라운드"로, "가볍게 누르고, 깊게 빠지다"라는 슬로건이 인상 깊었습니다. 18개 시군을 4개 테마 Zone으로 나누고, 각 Zone별로 4개의 게임 스테이지를 만들었죠. 이 팝업스토어의 핵심은 여행 루트 앱인데, AI 기반 감성 추천과 포토스팟 기능이 특징이었습니다. 

제안서 작성 후에는 이 앱의 개선 작업 지시서도 작성했습니다. 지도, 이동시간/거리, 사진, 일정 저장, 예산 요약, 다크모드, 스티키헤더 등 7개 기능을 우선순위별로 정리했죠.

## 30일차

드디어 DB-DEEP 강원 여행 앱의 핵심 7대 기능을 모두 구현했습니다! 카카오맵 연동, 이동 거리/시간 표시, Unsplash 사진, 일정 저장, 예산 요약, 다크모드, 스티키헤더 등 다양한 기능들이 차근차근 추가되었습니다.

이제 실제 모바일에서 UI를 테스트해 보고, 제안서에 앱 시연 화면을 추가할 계획입니다. 

한편 트리플의 9대 핵심 기능들도 대폭 업그레이드했습니다. 탭 전환, AI 요약 문구, 카테고리 마커 색상, 찜/저장 기능, 상세 모달 등 다양한 기능들이 추가되었죠. 특히 카카오맵과 타임라인 간 양방향 연동은 정말 중요한 기능이었습니다.

## 31일차

오늘은 UI/UX를 대폭 개선했습니다. 

첫째, 이미지 시스템을 완전히 재설계했습니다. 유명 관광지 사진들을 직접 매핑하고, 지역별/카테고리별 이미지 풀을 구축했죠. 이제 앱 내 어디서든 멋진 이미지를 만날 수 있게 되었습니다.

둘째, 카드 UI를 재설계했습니다. 각 카드 유형별로 디자인을 최적화했고, WCAG 색상대비 기준도 맞췄습니다. 또한 터치타겟 크기도 개선했죠.

셋째, 키오스크 및 반응형 대응도 완료했습니다. 세로모드 폰트 확대, 노치/홈바 대응, 접근성 개선 등을 통해 다양한 기기에서도 최적의 환경을 제공할 수 있게 되었습니다.

이제 실제 기기에서 더 꼼꼼한 테스트를 거칠 계획입니다.

## 32일차

오늘은 드디어 한국관광공사의 TourAPI 4.0을 연동했습니다! 그동안 정적 데이터로만 앱을 만들었지만, 이제 실제 관광정보 데이터를 가져와 사용할 수 있게 되었죠.

API 연동을 위해 Vercel 서버리스 함수로 프록시 서버를 만들었습니다. 이렇게 하면 API 키를 안전하게 보관할 수 있어 좋습니다. 또한 브라우저-CDN-서버 3단 캐싱 시스템을 구축해 API 호출 속도도 개선했습니다.

이제 관광지, 음식점, 숙박 정보를 TourAPI에서 가져와 앱에 반영했습니다. 특히 상세 정보(운영시간, 쉬는 날 등)도 잘 표시되도록 개선했죠.

다음에는 실제 기기에서 API 로딩 속도를 체감 테스트하고, 축제/행사 정보 연동도 검토해 볼 계획입니다.

## 33일차

오늘은 바이브코딩 프로젝트가 아닌 다른 앱, '지원해' 앱의 Phase 3 작업을 진행했습니다.

지원해 앱은 AI로 작성된 자기소개서를 공유하고 피드백을 받는 플랫폼입니다. 이번 Phase 3에서는 SEO와 공유 기능을 개선했습니다.

먼저 SEO 개선을 위해 메타 태그와 OG 태그를 추가했습니다. 이를 통해 검색 엔진과 SNS에서 더 잘 노출될 수 있게 되었죠. 

다음으로 카카오톡, 트위터, 링크드인 등 다양한 채널로 자기소개서를 공유할 수 있는 기능을 구현했습니다. 사용자들이 편리하게 자신의 소개서를 공유하고 피드백을 받을 수 있게 되었습니다.

이번 작업을 통해 지원해 앱의 서비스 품질이 한 단계 더 올라간 것 같습니다.

## 34일차

이번 주는 바이브코딩 프로젝트 대신 다른 프로젝트에 몰두했습니다. 바로 가상화폐 자동 매매봇 만들기였죠.

이 프로젝트의 목표는 실제 돈을 이용해 자동 매매봇을 만들어 보는 것이었습니다. 그동안 AI로만 프로젝트를 해왔지만, 이번에는 실전 코딩을 해보고자 했습니다.

먼저 바이낸스 API를 연동해 실제 계정에 접근할 수 있게 했습니다. 그리고 간단한 매매 전략을 구현해서 실제로 거래를 진행했죠. 처음에는 조금씩 돈을 투자해 보다가, 점점 규모를 늘려나갔습니다.

결과적으로 이번 프로젝트를 통해 실전 코딩의 중요성과 가치를 다시 한번 깨닫게 되었습니다. 앞으로도 이런 식으로 실제 돈을 걸면서 프로젝트를 해볼 계획입니다.

## 35일차

오늘은 자동 매매봇 프로젝트를 마무리하고 바이브코딩 프로젝트로 돌아왔습니다.

매매봇 프로젝트는 성공적으로 완료했습니다. 초기 투자금을 약 30% 정도 수익 냈죠. 물론 단기간에 큰 수익을 내기는 힘들었지만, 실제 거래를 통해 많은 것을 배울 수 있었습니다. 앞으로도 이런 식의 실전 프로젝트를 계속해나갈 예정입니다.

그리고 이제 다시 바이브코딩 프로젝트에 집중해보려 합니다. 그동안 TourAPI 연동과 UI/UX 개선 작업을 진행했는데, 이제 마지막 남은 과제는 SEO와 공유 기능 개선입니다. 

이번 주 내로 SEO와 SNS 공유 기능을 추가하여 DB-DEEP 강원 여행 앱의 개발을 마무리할 계획입니다. 그리고 이 앱을 실제로 운영해 보면서 사용자 반응과 피드백을 수집할 예정이에요.
